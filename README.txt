HOW TO ADD A NEW PROJECT
1. Upload the project files to GitHub, for example:
   projects/my-project/project.zip
   projects/my-project/cover.jpg
   projects/my-project/report.pdf
2. Open admin.html.
3. Fill in the project information.
4. Use paths relative to the website, e.g.:
   projects/my-project/cover.jpg
   projects/my-project/project.zip
5. Click "Download updated projects.json".
6. Replace data/projects.json in your GitHub repository with the downloaded file.
7. Commit/push. The project will appear automatically.

IMPORTANT
Because GitHub Pages is static, a browser cannot securely write new files into the public GitHub repository. The admin page therefore generates the updated projects.json for you. This avoids exposing a GitHub access token in your website.
